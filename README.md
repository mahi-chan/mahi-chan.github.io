# Portfolio

Personal portfolio — AI & computer-vision developer.
Built with React, TypeScript, Vite and Tailwind CSS.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

## Content

All site content lives in [`src/data/profile.ts`](src/data/profile.ts).

## Deploy

Pushing to `main` runs the GitHub Actions workflow, which builds the site and
publishes it to GitHub Pages.
